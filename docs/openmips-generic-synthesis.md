## Important limitations

This is a synthesis-flow smoke test, **not a physical area or timing result**.

- The generated I-cache BRAM, D-cache BRAM, and DSP blocks are black-box modules. Their FPGA/ASIC resource use is not included in the generic logic count.
- The pass uses Yosys generic cells without ABC technology mapping to a target library.
- No target device/library, timing constraints, placement, clock-tree synthesis, routing, or static timing analysis were supplied.
- The number 70,353 must not be interpreted as LUTs, standard cells, gate equivalents, or a silicon area estimate.
- The zero memory-bit count describes the reported generic netlist; it does not mean the integrated design has no memories, because generated memory IP is modeled as black boxes.

## Reporting automation

The workflow runs `scripts/summarize-yosys-report.py` against the final Yosys statistics block. It extracts the wire, wire-bit, memory-bit, and generic-cell counts and emits a Markdown summary with explicit interpretation limits. The summary does not infer warning counts from the statistics-only report. The raw statistics and JSON netlist remain available as run artifacts; the summary is not a substitute for target-specific mapping.

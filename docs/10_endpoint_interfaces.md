# 10 — Endpoint Interfaces

Potential endpoint categories:

- Thread
- Wi-Fi
- BLE
- Ethernet

For each endpoint, record:

- physical/device interface
- host/control interface
- packet/transaction format
- clock domain
- reset
- buffering
- backpressure
- error behavior
- DMA requirements
- security/configuration requirements

## Status

The four endpoint mapping is provisional and must not be treated as final architecture.

# 09 — Silicon Labs DVKs

## Purpose

The Silicon Labs development boards are an evaluation/reference input for understanding the wireless/networking side of the intended system.

## What this does NOT mean

The boards should not automatically be mapped one-to-one onto crossbar ports.

## Evaluation questions

- Which exact DVK/part is being evaluated?
- Which protocol does it demonstrate?
- What host interface is exposed?
- Is the interface SPI/UART/USB/other?
- Where is packet processing performed?
- What data/control path would connect to LOT?
- What clock/reset/CDC boundary exists?
- What evidence is needed from hardware versus RTL simulation?

## Status

Open until the exact boards and intended experiment are confirmed.

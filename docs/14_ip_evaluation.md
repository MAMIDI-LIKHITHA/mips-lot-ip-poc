# 14 — IP Evaluation

Candidate interconnect implementations identified in the project material include open-source and commercial/vendor options.

## Evaluation criteria

| Criterion | Question |
|---|---|
| Protocol fit | Does it match the confirmed bus? |
| Routing | Does it support required topology? |
| Arbitration | Is policy suitable? |
| Backpressure | Correct semantics? |
| Verification | Existing evidence/testbench quality? |
| Tool support | Works with target simulator/synthesis? |
| Technology | Portable or vendor-specific? |
| License | Can it be used for the intended POC/product? |
| Maintainability | Can the team modify/debug it? |

# 15 — License / Toolchain

Before importing third-party RTL, record:

- repository URL
- exact version/commit
- license
- dependencies
- vendor IP/tool license requirements
- simulator
- synthesis tool
- FPGA/device or silicon target
- vendor primitives
- permitted modifications
- whether code is reference-only or production-usable

## Principle

A technically good RTL block is not automatically usable IP. Licensing and toolchain compatibility are part of the engineering decision.
